## Controls


`tab` and `m` - and the button in the top right - toggle the galaxy map

`space` toggles build mode in which you can drag and drop tiles from the bottom (cant turn on while in the galaxy map)

holding `shift` in build mode lets you place multiple tiles at once

pressing `e` (while not typing a save name) will pause the game until you type a number (IN THE CONSOLE/TERMINAL) to add to your current fuel level

`WASD` moves the camera
